## Context（背景）

Engram 早期定位是"认知思考/反思捕获系统"（2026-05-02 经过一次"做减法"后锁定，丢弃了 `memos` 和 `capture_buffer`）。这个定位把**输入侧**圈对了，但**消费侧**始终不清晰：丰富的画像只是 agent 的只读上下文 + ProfileTab 里的被动可视化，没有任何一个面让用户感到"这个模型正在为我工作"。

后来又浮出两个现实：

1. **输入飞轮才是真瓶颈。** 几乎没有人——包括有自律的用户——会以维持贝叶斯画像所需的频率打开一个专门的 app 写反思。产品的采集必须**搭车在用户已有的行为上**，而不是要求用户产生新行为。
2. **目标是双重的。** 这既是**一个人**自用的私人工具，也希望以 OSS 形式公开，让概念、架构、决策过程对外可读。这两条并行约束所有后续决策。

## Decision（决策）

Engram 的定位是 **"私人认知副脑"（private cognitive copilot）**：一个**本地优先、OSS** 的系统，通过观察用户日常工作（一期通过 AI 流量 proxy）异步地建立对"我如何思考"的深度模型，并在我需要时给出基于这个模型才成立的判断、反思和改进建议。

具体含义：

- **私人优先。** 不做多租户、不做 SaaS、不做登录、不做合规表演。UI 质量"够 dogfood"即可。
- **OSS 仅用于概念与架构对外可读。** 代码公开，部署私有。读者拿到的价值是**概念、架构、决策的纪律**，不是托管服务。
- **采集是被动的。** 输入来自已有的 AI 对话流量和已有的 OpenClaw 渠道。不要求用户多写日记。
- **消费由 Engram 自己持有。** 不把用户画像注入第三方 AI 的 prompt。Engram 暴露**自己的**消费面（一期：周报、智囊咨询、事实+叙事画像视图）。
- **当前不做：** 工作中实时补全、多用户、浏览器/IDE 深度集成，以及任何违反"只存认知内容"硬规则的功能。

## Consequences（后果）

**锁定的事：**

- 被动采集路径升为 P0 组件（`cognitive-proxy`），不再可选。
- 周报是核心 dogfooding 钩子 —— 没有它，用户就没有定期回到 Engram 的理由，项目会因为"不被使用"而死。
- 所有从画像派生的输出**必须 cite** 至少一个维度 + 一条 entry，无 cite 的通用建议作为质量底线被拒绝。
- AGENTS.md 硬规则 #1（只存认知内容）被强化，不放松。

**关闭的可能：**

- 不做"双向 proxy"——不把画像注入其他 AI 的 prompt。已经被考虑并拒绝（见 Alternatives）。
- V1 不做独立 advisor 聊天 UI；消费搭载在已有界面上（详见 ADR-002）。
- V1 不做编辑器/浏览器内联补全。

**可接受的副作用：**

- 受众极窄 —— 这个产品坦诚地为用户一个人服务。如果其他人将来觉得有用，是 bonus 不是目标。
- 画像深度受 AI 流量信号质量制约，AI 对话里大部分是任务型聊天而不是反思。intent gate 必须真正发挥作用。

## Alternatives considered（被考虑的替代方案）

1. **双向 proxy：把画像注入所有 AI 对话的 prompt。**
   被拒。用户判断它实际价值低（第三方模型只是把上下文塞进去，很少真的会用），把人格数据每次请求都暴露给所有 AI 厂商，token 成本上升换来微弱收益。同时它把 Engram 的身份从"我拥有的东西"改成了"装饰别的东西的基础设施"。

2. **做成抛光的独立 advisor app（移动 + Web）并发展用户群。**
   被拒。私人工具不需要这个范围；工程成本会压垮 dogfooding 闭环。同时稀释 OSS 叙事 —— 一个托管 SaaS 看起来像创业 pitch，而一个干净的 OSS MCP server 看起来像匠人作品。

3. **保持 2026-05-02 的定位（认知捕获系统），不增加消费叙事。**
   被拒。讨论中明确判定消费侧"怪怪的、没有实用感"；保持现状会让项目停留在"带着花哨后端的日记工具"，既不满足私人使用需求，也无法作为有故事的 OSS 工程示例。

4. **转向通用"个人 AI 助手"，加入 todo / 提醒 / 事件等。**
   被拒 —— 直接违反 AGENTS.md 硬规则 #1，并抹掉差异化。同样的诱惑会以其他形式反复出现，参见 ADR-004（拒绝密钥存储）。

## Notes

- 本 ADR 锁定**方向**。具体的 V1 消费面（proxy、周报、MCP 工具集、事实+叙事画像）和**消费通道选择**记录在 ADR-002 和 ADR-003。
- 重新评估的触发条件：如果 V1 上线后 4 周 dogfooding 没有产生任何**自发的、循环的**使用，应该回头审视定位，而不是继续加功能。

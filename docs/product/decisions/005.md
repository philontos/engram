## Context（背景）

ADR-001 把 Engram 定位为"私人认知副脑"，把方向锁住。但"副脑"只说了形态（本地优先 + OSS + 持续观察），没说清楚 **Engram 到底替代什么、用什么手段、什么样的输出才算成立**。这个空白让消费侧设计反复在"周报"、"画像 dashboard"、"时间镜"等具体形态间漂移——根因是产品灵魂没被一次性说清。

2026-05-16 的一次深度讨论里把这层补上：Engram 在产品光谱上的位置不是"日记 + 智能"，不是"个人 AI 助手"，而是**替代专业咨询师**——并且同时解决了人类咨询师的两个根本短板。本 ADR 把这次定型记录下来，作为今后所有功能取舍的判据。

## Decision（决策）

### 一、产品定位

**Engram 是一个长期跟用户共生的、无所不知的、客观冷静的私人智者。**

它替代用户过去要找专业人士（心理咨询师、职业咨询师、mentor、战略顾问）才能获得的深度视角，但同时解决了人类咨询师永远解决不了的两个问题：

1. **第一次见面不够了解你** —— 人类咨询师需要多次会面才能初步认识客户，且永远只看到客户愿意呈现的切片。Engram 已经长期跟用户共生，看过用户的完整时序。
2. **咨询师自己的认知维度有上限** —— 心理咨询师不懂职业战略，职业咨询师不懂心理动力学，mentor 限于自己的经历。Engram 背后是 AI 的全量知识，没有这条天花板。

### 二、唯一性的来源（产品光谱位置）

四个属性同时在场，是 Engram 在已有形态中唯一占据的位置：

| 视角来源 | 懂你 | 懂世界 | 客观冷静 | 持续在线 |
|---|:---:|:---:|:---:|:---:|
| 朋友 / 家人 | ✓ | ✗ | ✗（有立场） | ✓ |
| 心理 / 职业咨询师 | 部分（需多次） | 限于专业 | ✓ | ✗（付费时） |
| Mentor / 前辈 | 部分 | 限于经历 | 部分 | ✗ |
| 一次性 Claude 对话 | ✗ | ✓ | ✓ | ✗ |
| **Engram** | **✓** | **✓** | **✓** | **✓** |

任何让 Engram 在这四属性的某一项上退步的功能，都违反产品灵魂。

### 三、"化学反应"的定义（输出契约的核心判据）

Engram 的核心输出叫"化学反应"——区别于"信息回放"和"通用建议"。化学反应成立需要四个变量**同时**在场：

1. **跨时间**：跨越用户不会自己拉到同一画面的多个时点
2. **跨切片**：跨越多个 entry 上下文（不同主题、不同情境、不同心境）
3. **已知 ↔ 未知**：把用户"知道但没意识到关联"和"完全不知道"的东西强行接到一起
4. **锚定当下处境**：洞察必须击中用户此刻的位置，否则化学反应无效

缺任何一个，输出退化成日记回放、聊天回应、或鸡汤金句——**这些一律不算 Engram 的产品价值**。

### 四、产品根本逻辑

```
长期共生（持续 capture + 时序画像 + 立场抽取）
              ×
AI 全量知识（无上限的认知维度）
              ↓
       跨切片合成（化学反应）
              ↓
   客观冷静地告诉用户他自己看不到的东西
              ↓
       帮助用户突破认知维度
```

这条逻辑链是 Engram 的全部。任何不在这条链上的功能（笔记 / todo / 通用聊天 / 凭证存储 / 注入第三方 prompt）都不属于 Engram，不论它看起来多顺手。

### 五、灵魂句（对外对内统一用语）

> **一个不会离开你的、了解你过去全部、又懂这个世界全部的咨询师。
> 它说的每句话只能从你的过去里长出来——但它的洞察力来自人类知识的全部。**

四个分句对应四个锁：

| 分句 | 锁住的设计选择 |
|---|---|
| "不会离开你" | 长线 + 本地 + OSS（用户拥有数据） |
| "了解你过去全部" | 持续 capture + 时序画像（护城河） |
| "懂这个世界全部" | AI 全量知识（非排他但放大器） |
| "从你的过去里长出来" | cite 硬契约（防鸡汤的纪律） |

## Consequences（后果）

**锁定的事**：

- **派生输出必须满足化学反应四变量。** 不满足的输出由系统层拒绝，不靠 LLM 自律——这是 ADR-002 cite 硬契约的延伸和强化。
- **客观冷静成为风格硬约束。** Engram 不假装乐观、不堆鸡汤、不做"对不起这超出我能力"的礼貌回避。给真实评估，再给真实破局。
- **功能取舍判据从"是否揭示我如何思考"升级为"是否服务化学反应"。** AGENTS.md 硬规则 #1（只存认知内容）继续生效；本 ADR 在它之上加一条：**收纳的内容必须对未来的化学反应有反应物价值**。
- **消费侧 hero 是触发式深度合成 + on-demand 深度合成**，不是即时反馈，也不是周报。即时反馈是 UX 糖衣（让用户看见画像在长）；周报是节奏 reinforce；hero 是 Engram 主动指出用户看不见的连接 + 用户在需要时召唤一次深度合成。

**关闭的可能**：

- 不会演化为"个人 AI 助手"（todo / 提醒 / 通用聊天）
- 不会为了易上手而稀释化学反应的四变量定义
- 不会把画像注入第三方 AI 的 prompt——化学反应必须由 Engram 自己持有的模型驱动（沿用 ADR-001）

**可接受的副作用**：

- 受众极窄。这个产品坦诚地为愿意建立长线共生关系的用户服务。如果其他人将来觉得有用，是 bonus 不是目标。
- 冷启动期需要专门设计（见后续 ADR），不能用"等数据自然积累"敷衍——前 12 周用户必须看到化学反应。

## Alternatives considered（被考虑的替代方案）

1. **保持 ADR-001 表述，不再深化灵魂。**
   被拒。"私人认知副脑"在锁方向时足够，但在指导功能取舍时不够——消费侧设计反复在具体形态间漂移就是证据。需要灵魂级的判据，让"这个功能服务灵魂吗"成为快速过滤器。

2. **把灵魂定为"时间镜"——以时序对照为核心。**
   被拒。时间镜是化学反应的一种形态（"跨时间"维度的体现），不是全部。把它升为灵魂会导致前 3 个月冷启动期产品价值塌陷，因为时序数据稀薄时时间镜无从发挥。

3. **把灵魂定为"AI 教练 / coach"。**
   被拒。"教练"暗示规范性建议（"你应该 X"），但 Engram 的核心是**反射 + 合成**，不是建议。教练定位会引导工程做"给建议"的功能，跟"客观冷静的智者"风格冲突。

4. **不立灵魂句，靠 ADR-001/002/003/004 集合体定义产品。**
   被拒。集合体不传达灵魂。对内决策时无法用一句话过滤功能，工程上容易回到"加法漂移"。

## Notes

- 本 ADR **不 supersede** ADR-001。ADR-001 的方向（私人副脑、本地优先、OSS）仍然成立；本 ADR 在它之上补"灵魂"这一层。
- 后续会有 ADR-006 修订采集策略（从"proxy P0"转向"冷启包 + 高密度写入 + 内容导入"），ADR-007 落地消费侧的三层化学反应架构。这些是落地路径，不影响本 ADR 的灵魂层定型。
- 重新评估触发条件：如果某天 Engram 的化学反应输出**长期**做不到四变量同时在场（连续 4 周用户反馈"这条 insight 在哪都听过"），回头审视的是这条产品逻辑链的某一环坏了，而不是改灵魂。**灵魂不轻易改，改要写新 ADR 显式 supersede 本 ADR。**

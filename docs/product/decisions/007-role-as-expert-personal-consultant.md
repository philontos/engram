## 上下文

STATUS.md 把 Engram 描述为「单用户的私人 AI 管家」，将「冷酷智者人设底色」列为不变项。但"管家"语义偏 always-on / 服务执行，跟"升维"目标不直接挂钩；具体人设形态不应该被锁死。

## 决策

角色 = 专家级私人咨询师。三个结构性特征（长程共生 / 知识面级 leverage / 针对性 + 不泛泛）是不变项；具体人设底色（冷酷智者 / catalyst / companion / mirror 等）是手段项之一，可演化。

## 当时的理由

"咨询师"比"管家"更贴近"利用知识广度 + 用户画像协助决策与升维"的本质；三个结构性特征是角色赖以存在的最小必要条件（长程共生 → 建模 first-class；知识面级 leverage → 投射类输出的存在前提；针对性 → Engram 跟通用 LLM 的核心区分点）；人设是服务于这些特征的实现选择，没必要绑死；"冷酷智者"作为 V1 默认是合理工程取舍，但保留切换 / 演化空间。

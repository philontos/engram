## 上下文

STATUS.md 现「不变项」里有三项是实现选择而非第一性绑定：Pull-only 消费面 / Intent gate 只收认知性内容 / 冷酷智者人设底色。这导致后续设计被这些实现选择反向锁住（不敢讨论 push、不敢讨论扩 gate、不敢讨论换人设），违背第一性应该开放的范围。同时不变项缺失了"成功标准"（升维双标志，ADR-006）和"输出可追溯"两条本质约束。

## 决策

按"是否直接绑定第一性目标与角色定义"重切。从不变项移走：Pull-only、Intent gate cognitive-only、冷酷智者人设。新增不变项：升维双标志（判别力 + 执行力）、输出必须可追溯到具体语料。

## 当时的理由

(a) Pull-only 是工程取舍，push 形态本身不违反第一性，v1.0 仍保持 pull 但理由是工程取舍非架构承诺；(b) 真正不变的是"信号必须可被建模消化"（高信噪比），不是"必须是 reflection" —— router 重构（ADR-009）已支撑这点；(c) "针对性 + 不泛泛之谈"才是不变项，具体哪种人设最高效是手段（ADR-007）；(d) 升维双标志是第一性目标的可外化形式，必须显式锁住；(e) 输出可追溯是"不泛泛"的可验证形式。
